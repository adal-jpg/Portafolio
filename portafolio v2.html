VR / MR (Unity & Quest 3) 2026

Entorno Interactivo en Realidad Mixta (Meta Quest 3 + MRUK + Nova UI)

Aplicación espacial en Realidad Mixta para Meta Quest 3 que escanea la habitación del usuario, permite posicionar mobiliario 3D a escala real.

1. Contexto

Las experiencias de comercio espacial en Realidad Mixta suelen carecer de comprensión real del entorno físico del usuario.

2. Reto

Integrar simultáneamente el escaneo espacial de paredes, piso y muebles reales en Meta Quest 3.

3. Enfoque

Arquitectura desacoplada combinando Meta Quest 3 Building Blocks, MRUK y Nova UI.

4. Ejecución

Implementación de reconocimiento de mallas y catálogo interactivo con Nova UI.

5. Resultado

Entorno fluido donde el usuario decora su espacio físico real con objetos virtuales persistentes.

6. Impacto

Consolidación de flujo de trabajo modular para computación espacial.

IA Local & Voz (Python) 2026

Ecosistema Local de Síntesis y Conversación por Voz (Python + Ollama + Piper TTS)

Sistema conversacional 100% local en Python y Flask que une transcripción con Whisper, inferencia rápida con modelos Llama en Ollama y síntesis neuronal.

1. Contexto

Las APIs en la nube introducen costos recurrentes, problemas de privacidad y latencia variable.

2. Reto

Orquestar STT, LLM y TTS completamente en local manteniendo tiempos de respuesta conversacionales.

3. Enfoque

Servidor ligero en Python y Flask con modelos cuantizados en Ollama y Piper TTS.

4. Ejecución

Configuración de Faster-Whisper, system prompt en Ollama y Piper TTS.

5. Resultado

Asistente de voz autónomo capaz de mantener diálogos dinámicos sin conexión a internet.

6. Impacto

Dominio sobre la optimización de inferencia local en CPU/GPU.

Python Flask Ollama Piper TTS
Full-Stack & WebSockets 2025

Sistema Web Multi-Dispositivo en Tiempo Real (Flask + WebSockets en Red Local)

Plataforma cliente-servidor en Python Flask y WebSockets diseñada para sincronizar estados visuales entre múltiples pantallas y teléfonos en red local.

1. Contexto

En instalaciones interactivas se requiere controlar vistas remotas desde un dispositivo móvil sin retrasos.

2. Reto

Eliminar el retardo del polling HTTP y garantizar sincronización instantánea en red local (LAN).

3. Enfoque

Arquitectura orientada a eventos con Python Flask y comunicación bidireccional por WebSockets.

4. Ejecución

Backend en Flask gestionando salas y frontend emitiendo eventos instantáneos.

5. Resultado

Sincronización inmediata entre múltiples dispositivos con latencia inferior a 30 ms.

6. Impacto

Base reutilizable para conectar interfaces web de control remoto con instalaciones físicas.

Python Flask WebSockets
